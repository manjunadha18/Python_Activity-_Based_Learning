## 2. About the Project

Python Activity-Based Learning is a practical programming project designed to develop problem-solving and logical thinking skills using Python. This project consists of 10 real-world case studies that demonstrate how Python programming can be applied to solve problems in different domains, such as education, healthcare, finance, transportation, retail, manufacturing, and event management.

Each case study focuses on understanding a problem, developing a logical solution, implementing the solution using Python, and analyzing the output.

---

## 3. Project Objectives

- To understand the fundamentals of Python programming.
- To develop logical and computational thinking skills.
- To apply Python concepts to real-world problems.
- To practice writing, executing, and debugging Python programs.
- To understand decision-making and calculation techniques in programming.
- To improve problem-solving skills through practical case studies.
- To gain experience in managing and sharing code using GitHub.

## 4. Case Studies

### Case Study 1: University Scholarship Allocation

**About:** This case study focuses on determining student eligibility for scholarships based on criteria such as academic marks, attendance, and family income. Python is used to evaluate the conditions and calculate scholarship eligibility.

### Case Study 2: Progressive Electricity Billing

**About:** This case study calculates electricity bills using progressive unit-based charges, fixed charges, and applicable surcharges. It demonstrates how Python can automate billing calculations.

### Case Study 3: Hospital Billing and Patient Classification

**About:** This case study calculates hospital expenses based on consultation fees, diagnostic tests, treatment charges, and applicable concessions. It demonstrates the use of conditional logic in healthcare billing.

### Case Study 4: Employee Payroll and Deduction Analysis

**About:** This case study calculates employee salaries by considering basic pay, allowances, overtime, incentives, and deductions. Python is used to determine gross salary and net salary.

### Case Study 5: Mobile Plan Cost Optimization

**About:** This case study compares mobile plans based on usage requirements and budget. Python helps calculate plan costs and identify a suitable option according to the given conditions.

### Case Study 6: Railway Fare and Reservation Calculator

**About:** This case study calculates railway ticket fares based on travel class, passenger details, and applicable concessions. It demonstrates the use of arithmetic operations and conditional statements.

### Case Study 7: Retail Billing with Multiple Discount Rules

**About:** This case study generates retail bills by considering product prices, quantities, and applicable discounts. Python is used to calculate the final bill amount after applying the discount rules.

### Case Study 8: Manufacturing Cost and Profitability Analysis

**About:** This case study calculates manufacturing expenses, total production costs, selling prices, and profits. It helps analyze business profitability using Python calculations.

### Case Study 9: Multi-Currency Travel Budget Analysis

**About:** This case study converts travel expenses between currencies and calculates total spending against a planned budget. It demonstrates mathematical calculations and budget analysis using Python.

### Case Study 10: Campus Event Financial Planning

**About:** This case study estimates campus event expenses, calculates expected revenue, and analyzes the event budget. Python is used to determine total expenses, revenue, and the resulting profit or loss.
